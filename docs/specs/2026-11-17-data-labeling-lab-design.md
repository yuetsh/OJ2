# OJ2 设计文档：「数据标注」—— 让学生当一回标注员的新板块

日期：2026-11-17
状态：**11-17 已实施，本机跑通，未提交。** 代码在：后端 `apps/api/src/routes/labeling.ts`（学生 + 全班情况）、`routes/admin/labeling.ts`（出题）、`services/labeling.ts`；契约 `packages/contract/src/labeling.ts`（含前后端共用的判对错）；前端 `apps/web/src/oj/labeling/`、`apps/web/src/admin/labeling/`；表在迁移 `0048_labeling`。 下面每一条都是一件一件讨论定下的。

## 1. 为什么要这个板块

让学生亲手给数据打标签，体会 AI 用的数据是怎么来的。**学生是标注员**，做的就是「标注」这件事本身，
不是学标注理论，也不是替别的功能收集素材。

不是 OJ，也不复用自学；和「数据分析」并列，放在顶栏「实验室」下拉里。
界面上叫 **「数据标注」**；代码、表名、路由一律用 `labeling`，与界面叫法脱钩。

## 2. 拍板汇总

| # | 事项 | 拍板 |
|---|---|---|
| 1 | 学生做什么 | **当标注员**：看一条数据，选一个标签 |
| 2 | 数据类型 | **文字分类 + 图片分类**。画框、多选以后再说 |
| 3 | 谁出题 | **老师在后台自己传** |
| 4 | 有没有对错 | **有标准答案**：每条数据老师定好正确标签 |
| 5 | 什么时候知道对错 | **每条标完立刻告诉对错，错了可以改，标对才算过** |
| 6 | 一节怎么组织 | **一节只放一种类型**，一节一套标签，**10–20 条** |
| 7 | 单选还是多选 | **只做单选**；多选（全中才算对？）以后再加 |
| 8 | 老师看什么 | **按人** 和 **按数据** 两种视图，同一页切换 |
| 9 | 学生页形态 | **一次一条**，顶上显示进度（7/15），标对后跳下一条；手机为先 |
| 10 | 标错 / 标对说什么 | 标错只说「不对，再看看」；**标对后显示老师写的一句理由**（可不填，不填不显示） |
| 11 | 怎么录入 | **文字批量粘贴、图片批量上传**，录完在列表里逐条改、拖动排序 |
| 12 | 怎么进课堂 | **独立入口**，不接课堂任务 / 成就 / 看板娘 / 排名；做完一节只记「已完成」 |
| 13 | 实体标注 | **11-17 追加，第一版一起做**：在一句话里把人名、地名这类词划出来、标上类别。见第 3.5 节 |

没单独问、照「数据分析」做法定的：每节有「学生可见」开关（没开是草稿）；老师可在后台试做；进度存库。

**看设计稿时定的三处（11-17）**：

- 「按数据」整行标橙：标错的人多半选了同一个（实体标注：同一处错误），且人数比标对的还多 → 可能答案定错了。
- 图片题没有文字名称，后台和老师视图只显示缩略图。
- 批量粘贴上方保留一行格式说明；「按人」视图里「一次就对从少到多」这类排序说明**不要**。

## 3.5 实体标注（第三种类型，11-17 追加）

一节的类型从两种变三种：**文字分类 / 图片分类 / 实体标注**。实体标注的「标签」就是类别（人名、地名、国家…），
同样 2–6 个、每个最多 10 字。

| # | 事项 | 拍板 |
|---|---|---|
| 1 | 标错时说多少 | **说哪一类问题，不说是哪个词**：「还少标了 1 处」「有 1 处类别不对」「多标了 1 处」 |
| 2 | 手机上怎么标 | 每个字是能点的小格子。**先在上方选类别，再点开头的字、点结尾的字**；一个字的词在同一个字上点两次。点已标的那段可以删掉 |
| 2b | 电脑上怎么标（11-17 改） | **手机不变。** 用鼠标时去掉上方的类别按钮：**按住拖过去选字，松开后在选中那段上方弹出类别**，点一个就标好（只点一个字也弹）；拖到已标的段跟前就停住。点已标的那段弹同一个条，可以换类别或删掉。按 `(hover: hover) and (pointer: fine)` 认鼠标。不用浏览器自带的选中文字（手机会弹系统菜单、安卓按词库自动选词）。设计稿 LabelSpanDesk |
| 2c | 标题里的类别名（11-17 加） | 标题里出现这一节的类别名，就铺上那一类的颜色（手机电脑都铺），学生一眼知道哪个颜色是哪一类；标题没写全类别，就在标题下补一行带色块的类别 |
| 3 | 老师怎么出题 | **两种都支持**：粘贴时认 `[李白](人名)出生在[碎叶城](地名)` 这种写法（理由照旧放 Tab 后面）；列表里也能用和学生一样的点选来标、来改 |
| 4 | 老师「按数据」 | 每句显示**第一次全对几人** + **这一句最常见的那处错误**（「漏标『碎叶城』12 人」/「『长安』标成人名 5 人」/「多标『唐朝』4 人」）；某处错误的人数比全对的多 → 整行标橙 |

没单独问、按最简单定的：

- **要交一次才判**：标完点「提交」；分类仍是点一下就判。对了显示理由，规则和分类一样（错了可以改，对了才过，只能往前）。
- **一次就对** = 第一次提交就全对。
- **两段不能重叠**（不支持「北京大学」里再标「北京」这种嵌套）。
- 对错看「从第几个字到第几个字 + 类别」完全相同；一句里没有要标的词也允许（答案为空，学生直接交就对）。
- 作答记录多存一份**第一次提交的那几段**（jsonb，很小），「按数据」的常见错误由它对照**当前**答案现算，和分类口径一致。
- 做完的错题页：显示正确标好的句子，下面是「你第一次标的」，再是理由。

## 3.6 框选（第四种类型，11-17 追加并实施）

在一张图上框出所有要标的东西，每个框选一个类别（像自动驾驶认车认人用的标注）。类别同样 2–6 个、每个最多 10 字。

| # | 事项 | 拍板 |
|---|---|---|
| 1 | 一张图框几个 | **框出所有、每个框选类别** |
| 2 | 怎么算对 | 学生的框和答案的框**重合一半**（交并比 ≥ 0.5）就算这一个框对；全部框对、类别也对才算这一条对。重合了但不到一半算「框歪了」，完全没碰到算漏一个 + 多一个。门槛写在代码里，以后可改 |
| 3 | 手机 | **不做**，也不做任何专门处理（不提示、不隐藏、不为触屏适配） |
| 4 | 第一批的图 | 从网上找能免费使用的照片（公有领域 / CC0），避开能看清正脸的人；老师自己拍的以后再加 |
| 5 | 画完能不能调 | **能**：点已画的框，四角出小方块，拖角改大小、拖中间挪位置；弹条照旧换类别 / 删掉 |

照实体标注定的：用鼠标拖出框，松手在框上方弹类别（和 3.5 节电脑拖选同一套）；错了只说哪类问题（「还少框了 1 个」「有 1 个框类别不对」「有 1 个框歪了」「多框了 1 个」），不说是哪个；
要交一次才判；框之间可以重叠（人骑在车上）；一张图里没有要框的也允许；老师「按数据」看第一次全对几人 + 最常见那处错；做完的错题页并排「应该是 / 你第一次框的」。
框的坐标按图片的比例存（0–1），和显示多大无关。这一类的页面比 640 宽，图才看得清。

## 3. 一节「数据标注」长什么样

```
数据标注：判断外卖评价是好评还是差评
  类型：文字分类    标签：好评 / 差评      （一节一套标签，2–6 个）
  ├─ 第 1 条：「送得很快，菜还是热的」   正确：好评   理由：「很快」「热的」都是夸奖
  ├─ 第 2 条：「等了一个小时，退货」     正确：差评   理由：…
  └─ …（共 10–20 条）
```

## 4. 学生页

- 列表页：各节卡片，显示类型（文字 / 图片）、条数、自己做到几条 / 已完成。
- 一节页：屏幕只有一条数据（一段文字或一张图），下面是标签按钮，顶上进度 `7/15`。
  - 点标签 → **对**：显示老师写的理由（有才显示），再点「下一条」；**错**：只提示「不对，再看看」，按钮可再点。
  - 不显示「错了几次」，不提示答案，不在错时给任何线索。
  - 图片大图适配手机宽度；按手机先设计、先验收。
  - 最后一条标对 → 这节完成。
- 做完后再进来怎么办，见第 8 节（待定）。
- **对错在服务器判**：页面上拿不到正确标签，每点一次标签发一次请求，服务器判完回「对 / 不对」，
  对了才连理由一起回。否则学生开 F12 就能看到整节答案。

学生界面全中文、不用「他」、不出现英文（沿用既有约定）。看板娘在桌面端全站都在（`shared/layout/default.vue`），
这里照样会出现；「不接看板娘」指不加专门的台词和成就，和「数据分析」一样。

## 5. 后台出题

- 新建一节：标题、说明、类型（文字 / 图片）、标签列表。**类型建节时定，之后不能改**（改了数据就对不上）。
- 文字批量粘贴：每行一条，`文字 | 正确标签 | 理由`，理由可省。标签不在这节标签集里要逐行报错。
  **分隔符同时认 Tab、`|` 和全角 `｜`**：老师多半在 Excel / WPS 里整理好再复制，粘过来是 Tab 分隔，只认 `|` 会整批报错。
- 图片批量上传：一次选多张，传完在列表里逐张选标签、可填理由。格式按文件头认（复用 `services/image.ts` 的 `sniffImageExtension`）。
  **还有条目没选标签时，不让打开「学生可见」**（不然学生会卡在一条永远标不对的数据上）。
- 列表里逐条改、删、**拖动排序**（顺序就是学生做的顺序）；条数超过 20 提示但不拦。
- 「学生可见」开关；试做入口。

## 6. 老师看全班

同一页两个视图切换：

- **按人**：每个学生做到第几条、一共错了几次；没开始 / 进行中 / 已完成分组。
- **按数据**：每条数据全班有多少人**第一次就标错**、最常标成什么。用来找出难题，也用来发现标准答案本身有问题。

## 7. 数据与实现要点（实施时再细化）

- 表（新迁移）：节、数据条、每人每条的作答记录、排序。
  作答记录要有：**第一次选的是哪个标签**、错的次数、通过时间。「按数据」视图的「最常标成什么」要靠第一项，
  只记「第一次对不对」是算不出来的。
- 图片存放：参照「数据分析」素材存库（bytea）的做法，只针对新素材，不碰现有文件。
  「数据分析」的素材接口是按附件下载（`content-disposition: attachment`），图片要在页面里直接显示，得单开一个接口。
- 契约进 `packages/contract`；出参用 `satisfies`；加路由后跑 `check:routes`。
- 前端基线 Chrome 105；时间一律走 `time.ts`；判题状态码无关。
- 前端放 `apps/web/src/oj/labeling/`，后台放 `apps/web/src/admin/labeling/`；顶栏「实验室」下拉加一项。

## 8. 实施时再定（11-17 已全部定完）

- ~~一节标签数量上限、单个标签最长字数~~ **定为 2–6 个，每个最多 10 个字。**
- ~~图片大小 / 张数上限与压缩~~ **上传时在浏览器里缩到长边 1280px，单张最大 2MB**（学生多在手机上看，一节十几张）。
- ~~做完后再进来：只看还是能重做~~ ~~两个标签时学生要不要看到「一次就对」~~
  **11-17 拍板：做完显示「一次就对 12/15」，下面列第一次标错的那几条（正确标签 + 理由）。不重做。**
  做完再进来看到的就是这一页。只有两个标签时「标对才算过」人人必过，所以给学生看的是「一次就对」。
  老师新加条目后，学生先做完新加的，再回到这一页。
- ~~老师「试做」是否计入进度~~ **11-17 拍板：不计入**（老师视图只统计 `STUDENT_ROLES`，和「数据分析」一样）；
  **非学生角色的结果页多一个「重来」按钮**，清掉自己这一节的记录，好在改完题后再试。学生看不到这个按钮，接口也只认老师。
- ~~学生开始做之后，老师改了标准答案 / 增删条目怎么办~~ **11-17 拍板：记录保留，按新答案重新算。**
  - 统计类的数字（第一次标对没有、最常标成什么）都由「第一次选的标签」对照**当前**答案现算，不落库。
  - 「这条已通过」保留：学生当时按当时的答案标对了，不因为老师改答案被打回去重做。
  - 「这节已完成」不单独存，按当前全部条目现算：老师**新加**条目，做完的学生会变成「还差几条」；删条目则直接不算。
  - 「错了几次」照存的算，不随改答案重算（只是给老师看谁卡住了，不值得为它存每一次的选择）。
- ~~一次一条能不能跳过、能不能往回翻~~ **11-17 拍板：只能往前**，标对一条才出下一条，不跳过、不往回翻。
  回看理由靠做完后的错题页。

## 8.5 实验室是试验性质：要能整块拆掉

「数据分析」「数据标注」都属于顶栏的「实验室」，**后面留还是去掉都不一定**。所以实现上守这几条：

- **自成一块**：前端只在 `oj/labeling/`、`admin/labeling/`，后端只在 `routes/labeling.ts`、`routes/admin/labeling.ts`、
  `services/labeling.ts`，契约单独一个文件。不往现有模块里塞逻辑。
- **对共享代码的改动压到最少**，照「数据分析」实际碰到的共享文件，只有这些地方加几行：
  `db/schema.ts`（表定义）、`apps/api/src/index.ts` 和 `routes/admin/index.ts`（挂路由）、契约 `index.ts`（出口）、
  `apps/web/src/routes.ts`（前台和后台路由）、`Header.vue` 的 `labLinks`、后台侧栏 `shared/layout/admin.vue`、
  `oj/api.ts` 和 `admin/api.ts`（各加一段，照「数据分析」那段的写法）。
  不改题目、提交、统计、成就、看板娘的任何代码，也不复用它们的表。路径用 `/labeling`，和数据分析的 `/data-analysis` 不同的一级路径，
  顶栏按一级路径判高亮，不会串。
- **表独立**：新表只被这个板块引用，不被别的表外键指向；将来下线 = 一份 drop 迁移 + 删上面那些文件。
- **不抢功能**：不接统计、不接成就，也就没有「删了会连累别处」的问题（第 12 条已定）。
- **别为它做重投入**：第 8 节没拍板的细节取最简单的做法；不为「万一以后要留」提前设计扩展点。

## 9. 明确不做（第一版）

多选、画框、半自动标注、标注一致程度统计、作品墙、接课堂任务 / 成就 / 看板娘 / 排名。
