# OJ2 设计文档：「训练模型」—— 让学生改数据、把模型训到达标的新板块

日期：2026-11-17
状态：**11-18 已实施并上线。** 代码在：后端 `apps/api/src/routes/model-training.ts`（学生 + 全班情况）、`routes/admin/model-training.ts`（出题）、`services/model-training.ts`；契约 `packages/contract/src/model-training.ts`（含前后端共用的朴素贝叶斯）；前端 `apps/web/src/oj/model-training/`、`apps/web/src/admin/model-training/`；表在迁移 `0051_model_training`。设计稿在「重设计」画布的「训练模型」页。 下面每一条都是一件一件讨论定下的。

## 1. 为什么要这个板块

让学生亲手训练一个文字分类的小模型，体会**模型的本事全来自数据**：标错了它就学错，缺哪类它就不会哪类，
一边倒它就只会猜多的那边；准确率要拿没见过的数据测才算数。

学生学的不是算法，是「找数据的毛病、改好数据」这件事。和「数据标注」「数据分析」并列，放在顶栏「实验室」下拉里，
按门槛排在两者之间：**数据标注 → 训练模型 → 数据分析**（不用写代码，但要看懂准确率、会顺藤摸瓜）。

界面上叫 **「训练模型」**；代码、表名、路由一律用 `model-training` / `model_training`，与界面叫法脱钩。

## 2. 拍板汇总

| # | 事项 | 拍板 |
|---|---|---|
| 1 | 什么数据 | **第一版只做文字分类**。表格数据（判断树）放第二版，图片不做 |
| 2 | 和数据标注的关系 | **不挂钩**。标注每节 10–20 条，太少训不出东西；训练数据由老师单独准备 |
| 3 | 学生做什么 | 老师给一批**埋了毛病**的训练数据（标错、缺一类、一边倒），学生 训练 → 看判错 → 改/补数据 → 再训练，**准确率到老师定的线算完成** |
| 4 | 测试怎么分 | **两份**：「练习测试」判错的条目给学生看，用来找线索；「最后考」只给分数，**达标看它**。防学生把测试题抄进训练集 |
| 5 | 怎么找要改的数据 | 点一条判错的练习测试 → 标出让它判错的字（越红越关键）→ 下面列训练集里**含同样关键字**的条目，当场改。不做相似度算法 |
| 6 | 辅助 | 顶上常驻各类条数（「好评 250 · 差评 50」）；整张表能搜、能按标签筛 |
| 7 | 电脑还是手机 | **电脑为先**（左判错例子、右训练数据并排）。手机能打开、一栏往下排，不专门优化 |
| 8 | 能怎么改 | **改标签、删掉**（不是评论的脏数据）、**新增最多 30 条**（定死；防刷量）、**一键恢复原样**（确认一次，训练记录保留） |
| 9 | 各改各的 | 每个学生一份数据，互不影响；记每次训练的准确率，显示成「62% → 71% → 79% → 86% 达标」 |
| 10 | 达标以后 | 算做完，**给复盘**揭开埋的毛病：「标错 24 条，你改对 19 条」，没找到的能点开看；老师写的一段说明。达标后能接着改，记最高；完成不撤销 |
| 11 | 最后考的那份 | **永远不揭开**，只给分数（同一节换班复用） |
| 12 | 老师出题 | 从 Excel **粘四列**：句子 / 给学生的标签 / 正确标签 / 用在哪（训练 · 练习测试 · 最后考）。两个标签不同 = 故意标错 |
| 13 | 达标线怎么定 | 出题页替老师试跑两次：原始数据的**起点**、全改对的**上限**；线定在中间，页面给建议 |
| 14 | 复盘里的其余毛病 | 「反话少」「一边倒」系统认不出来，**老师写一段话**，达标后显示 |
| 15 | 老师看全班 | **按人 / 按数据**两种视图，见第 6 节 |
| 16 | 怎么进课堂 | **独立入口**，不接课堂任务 / 成就 / 看板娘 / 排名 |
| 17 | 谁出第一批课 | **我来出**，老师以后用同一个出题页 |

## 3. 一节「训练模型」长什么样

一节 = 一套标签（2–6 个，每个最多 10 字，与数据标注一致）+ 三份数据 + 一条达标线 + 一段复盘说明。

| 数据 | 条数（参考） | 学生看得到 | 用途 |
|---|---|---|---|
| 训练 | 200–600 | 全部（带「给学生的标签」） | 学生改的就是它 |
| 练习测试 | 约 50 | 判错的条目 + 判成了什么 | 找线索 |
| 最后考 | 约 100 | **只有分数** | 判达标 |

示例（第一批课的方向）：外卖评论好评/差评（埋标错 + 反话少 + 一边倒）、短信正常/广告/诈骗、新闻栏目多分类。
**照数据标注的经验，默认往难里出**，每条都要细读。

## 4. 学生页（电脑为先）

- **顶上**：标题、各类条数、达标线、准确率那一串（62% → 71% → …）、「训练」按钮、新增还剩几条、「恢复原样」。
- **左栏 · 练习测试判错的**：每条显示句子、正确标签、模型判成了什么。点开后句子里的字按「让它判成这一类」的程度上色。
- **右栏 · 训练数据**：默认列出「含当前选中关键字」的条目（默认取最红的那个；点句子里别的红字可以换）；
  每行能改标签、删掉。顶上切到「全部」可以搜索、按标签筛。底部「新增一条」。
- **改过的条目**有标记（改了标签 / 新加的），删掉的能在「全部」里找回。
- **达标后**：顶上换成「达标了」+ 复盘（标错的找到几条、没找到的列表、老师的说明），页面照样能继续改、继续训练。

## 5. 后台出题

- 基本信息：标题、标签、达标线、复盘说明、学生可见开关、拖动排序（照前两个实验室）。
- **粘贴四列**（Tab 分隔，Excel 直接复制）：句子 / 给学生的标签 / 正确标签 / 用在哪。
  测试的两份只填正确标签（「给学生的标签」那列留空）。粘完列表里能逐条改。
- **试跑**：页面显示「原始数据训练 → 最后考 xx%」「全改对训练 → 最后考 yy%」，并建议达标线（两者之间偏上）。
  达标线高于上限时直接拦住，不让公开。

## 6. 老师看全班

同一页两个视图切换（只统计 `STUDENT_ROLES`）：

- **按人**：学生 / 最高准确率 / 训练几次 / 标错的改对（19 / 24）/ **改坏了**（原本标对、被改成错的条数）/ 是否达标。
  没达标的在前，按准确率从低到高。「训练 2 次」= 没动手；「训练 9 次、改坏 6 条」= 在乱改。
- **按数据**：故意标错的条目按「全班几人改对」从少到多排（排前面的 = 这节课最值得讲的）；
  另列**被最多人改坏**的条目（往往是句子有歧义或出题有问题）。

## 7. 数据与实现要点（没单独问，我定的）

- **算法：朴素贝叶斯**，特征是单字 + 相邻两字。几百条一次训练几毫秒；每个字（词）对判成某一类的贡献可以直接算出来，
  「越红越关键」就是它。纯函数放契约 `packages/contract/src/model-training.ts`，前后端共用。
- **训练在服务器上跑**（讨论时说过「在浏览器里算」，这里改掉）：最后考的句子不能发到浏览器，否则开发者工具一看就漏了；
  而改动本来就要存库。所以「训练」= 把这次的改动存上 → 服务器用当前数据训练 → 跑两份测试 → 回练习测试的逐条结果和
  最后考的分数。几百条在 2 核服务器上也是毫秒级，**不用新镜像**。
- **学生的数据存改动，不存整份**：改了标签的（条目 id → 标签）、删掉的 id、新增的（≤30 条）。老师改了原始数据，
  学生的改动按 id 套上去，被老师删掉的条目自然跳过。
- **每次训练记一行**（练习测试准确率、最后考准确率、时间），给「62% → 71% → …」、「训练几次」、「最高准确率」用。
  「达标」记第一次达标的时间，之后不撤销。
- **改对 / 改坏**按学生当前数据对照「正确标签」现算，不落库。
- 表（新迁移，只建表）：节、数据条、每人一份改动、每次训练记录。照 [数据标注第 8.5 节](2026-11-17-data-labeling-lab-design.md) 的规矩自成一块、能整块拆。
- 前端放 `apps/web/src/oj/model-training/`、`apps/web/src/admin/model-training/`；路径 `/model-training`；
  顶栏「实验室」下拉插在「数据标注」和「数据分析」之间。契约出参用 `satisfies`；加路由后跑 `check:routes`。

## 8. 实施时定的（11-18）

- 新增的条目最多 **100 字**；手机上一栏往下排时，判错的在上、训练数据在下。
- 老师「重来」照数据标注：非学生角色多一个按钮，清掉自己这一节的改动和训练记录。
- 学生把故意标错的那条**删掉，也算找到了**（复盘、老师「标错的改对」同一口径）；删掉好数据不算改坏。
- 达标后复盘里「没找到的」先显示 8 条，其余点开。
- **上次训练后一处没改，「训练」按钮是灰的**；服务器同样不记重复的一次（模型是确定的，结果一样，连点会刷出一串一样的分、老师的「训练几次」失真）。
- 学生页顶上那串准确率前面**不写「最后考」**（用户：看不懂、也不需要），旁边有达标线就够；后台页签仍叫最后考。
- 句子完整显示、折行，不截断（短信判断诈骗的关键词常在后半截）。
- 选标签一律是一排按钮、点一下就改；标签加起来超过 16 个字才换成下拉。

**出题的经验**（第一批三节：外卖评论 好评/中评/差评、短信 正常/广告/诈骗、新闻 体育/科技/财经/娱乐）：
- **至少三个标签**：只有两个时改数据就是「翻过来」，不用动脑（用户提的，第一节因此加了中评）。
- 随机标错几十条朴素贝叶斯几乎不受影响，要**成系统地标错**（同一类说法一起标错）才压得下起点。
- 测试句和训练句出自同一批句式会被模型背下来（全改对 100%），**每类句式留三分之一只进测试**。
- 三节各埋不同的毛病，过线的路也不同：第一节要改对大部分、补中评有帮助；第二节改对或补诈骗都能过；第三节只补过不了、非改不可。
- 公司、明星、运动员一律虚构。

## 9. 明确不做（第一版）

表格数据 / 判断树、图片分类、写代码训练（那是数据分析多几节课）、换算法或调参数、
和数据标注共用数据、接课堂任务 / 成就 / 看板娘 / 排名、新增条数让老师自己定。
